servediff notes: startup logs, read as facts

servediff reads a vLLM or SGLang startup log into named facts (“backend.moe was VLLM_CUTLASS in one run and MARLIN in the other”) so an upgrade can be compared on what the server actually ran with, not on the flags you passed.
